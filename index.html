Cara Main Multiplayer (Netplay):

  1. Pemain 1 klik "Start Game" di layar hitam.
  2. Setelah game mulai, arahkan mouse ke bagian bawah layar emulator untuk memunculkan menu.
  3. Klik tombol Netplay (ikon dua orang).
  4. Pilih Start Netplay Session.
  5. Salin link yang muncul dan kirim ke pacarmu.
  6. Pacarmu cukup klik link tersebut untuk bergabung!

Kontrol Player 1: Tombol Panah (Gerak), Z, X, A, S (Aksi), Enter (Start).
